About the dataset

This tool provides access to the bioactivity cluster similarity for 1,883 reference (landmark) compounds as determined using subprofiles derived from the Cell painting analysis in U2OS cells upon compound treatment for 20 h (Cell painting dataset from Pahl et al.).
